📜 סבא יוסף

סוכן שבועי שמחבר בין אקטואליה ישראלית לפרשת השבוע דרך מפרשים — הכל בעברית, מונע בינה מלאכותית

Claude AI + Sefaria + חדשות ישראליות

איך זה עובד?

הסוכן רץ כל יום חמישי, אוסף חדשות ופרשת שבוע, ומייצר מפת קשרים אינטראקטיבית. אתה בוחר מה מעניין אותך, והסוכן כותב לך דבר תורה מותאם אישית.

1

איסוף אוטומטי

כל יום חמישי ב-08:00, הסוכן אוסף חדשות מ-6 מקורות ישראליים, מוריד את פרשת השבוע מ-Sefaria עם עשרות מפרשים, ומזהה מועדים יהודיים קרובים.

2

מפת קשרים

Claude מנתח את החדשות והפרשה ומזהה קשרים תמטיים. התוצאה מוצגת כמפה אינטראקטיבית — חדשות בצד ימין, נושאי פרשה בצד שמאל, קווים מחברים ביניהם.

3

בחירת נושאים

לחץ על חדשות ונושאי פרשה שמעניינים אותך. הקווים המחברים מתעדכנים בזמן אמת. אפשר גם להוסיף נושאים חופשיים משני הצדדים.

4

הצעות דבר תורה

על בסיס הבחירות שלך, Claude מייצר 5 הצעות לדבר תורה — כל אחת עם כותרת, תזה, מתאר ומקורות ממפרשים. הטקסט נכתב בזמן אמת על המסך.

5

עריכה עם AI

בחר הצעה ופתח אותה לדבר תורה מלא. עורך טקסט עשיר (RTL) עם צ'אט AI בצד — "הוסף מקור מרש"י", "חזק את הנקודה הזו", "קצר פסקה".

6

דף מקורות PDF

כשסיימת, ייצר דף מקורות מעוצב להדפסה — כותרת, טקסט דבר התורה, ותיבות מקורות ממפרשים. מוכן לחלוקה בבית כנסת.

התקנה והפעלה

דרישות מקדימות

  • Python 3.12+
  • Node.js 18+
  • Claude Code CLI מותקן ומחובר
  • WeasyPrint system deps

Backend

# Clone the repo git clone https://github.com/OshriNap/saba-yosef.git cd dvar-tora # Setup Python backend cd backend python -m venv .venv source .venv/bin/activate pip install -e ".[dev]"

Frontend

cd frontend npm install

הפעלה

# Start both servers ./scripts/run-server.sh # Install Thursday cron (auto-collect every Thursday 08:00) ./scripts/install-cron.sh # Manual data collection cd backend && python -m cron.weekly_prep
